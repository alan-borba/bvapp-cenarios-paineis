# Cenários de teste funcional

Esta pasta guarda a documentação, em Markdown, dos dez cenários de teste funcional do épico Gestão de Painéis Solares (#24189) do BVapp.

Os cenários estão separados pela Feature que testam. Cada arquivo traz um cenário completo: requisitos relacionados, fluxo principal e alternativos, regras de negócio, dados, resultados esperados e autoria.

Esta pasta não tem código executável nem scripts de teste. Os cenários poderão ser aproveitados em etapas futuras de implementação e automação.

## Cenários por Feature

- [crud/](crud/): CT001, que reúne cadastrar, consultar, atualizar e excluir (Features #24258, #24260, #24261 e #24262).
- [inclusao/](inclusao/): CT002 a CT006 (Feature #24258 — Inclusão de novos painéis solares).
- [consulta/](consulta/): CT007 e CT008 (Feature #24260 — Consulta de painéis solares).
- [atualizacao/](atualizacao/): CT009 (Feature #24261 — Atualização de painéis solares).
- [exclusao/](exclusao/): CT010 (Feature #24262 — Exclusão de painéis solares).

Consulte o [README principal](../README.md) para o catálogo completo.
